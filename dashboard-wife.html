Google Drive Backup

Auto-saves a JSON backup of all your data to your Google Drive every Sunday (and on demand). Sign in once — token persists across sessions.

⚠ Setup needed
Google OAuth requires this page to be served from http://localhost or https:// — not file://.
Fastest fix: Open VS Code → install "Live Server" extension → right-click dashboard.html → "Open with Live Server". Or host it free on GitHub Pages.

1. One-Time Setup

You need a free Google OAuth Client ID (5-min setup):

  1. Go to console.cloud.google.com/apis/credentials
  2. Create a Project → enable Google Drive API
  3. Credentials → Create Credentials → OAuth Client ID → Web Application
  4. Under Authorized JavaScript origins, add the URL where you'll open this page (e.g. http://127.0.0.1:5500 for VS Code Live Server, or your GitHub Pages URL)
  5. Copy the Client ID and paste below
